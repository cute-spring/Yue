## Product Boundary

Yue is a trusted AI workbench and skill runtime platform. It is not just a coding agent, and it is not a skill authoring IDE.

The implementation tickets should preserve that boundary by building visible workbench modes, durable workspace artifacts, evidence and provenance behavior, and approval-gated durable state changes.
