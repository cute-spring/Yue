# 05 - Connect early workbench modes through artifact handoffs

**What to build:** Clarify briefs, handoffs, and questionnaires can reference each other as workspace artifacts so the first three MVPs feel like one workbench flow.

**Blocked by:** 02 - Clarify Mode creates a decision brief; 03 - Session Handoff creates a continuation artifact; 04 - Discovery Questionnaire creates a stakeholder artifact.

**Status:** ready-for-agent

- [ ] A Clarify brief can be used as context for a Session Handoff or Discovery Questionnaire.
- [ ] A Session Handoff can reference Clarify briefs and questionnaires created in the same workspace.
- [ ] A Discovery Questionnaire can link back to the decision brief or handoff that produced it.
- [ ] Artifact references are durable enough to be useful in a later workspace session.
- [ ] The connected flow does not trigger downstream work automatically without user action.
