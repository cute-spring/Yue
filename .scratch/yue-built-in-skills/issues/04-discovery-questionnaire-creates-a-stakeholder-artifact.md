# 04 - Discovery Questionnaire creates a stakeholder artifact

**What to build:** A user can turn a human information gap into a workspace questionnaire with context, prioritized questions, answer stubs, and no external send.

**Blocked by:** 01 - Establish built-in workbench mode contract.

**Status:** ready-for-agent

- [ ] A user can invoke Discovery Questionnaire from a stated human information gap.
- [ ] Yue gathers the minimum setup needed for recipient, objective, and missing knowledge.
- [ ] The generated questionnaire includes context, prioritized questions, answer stubs, and decision prompts where useful.
- [ ] The questionnaire is saved as a workspace-attached artifact.
- [ ] The artifact separates fact questions from decision or preference questions.
- [ ] No questionnaire is sent externally without explicit user approval.
