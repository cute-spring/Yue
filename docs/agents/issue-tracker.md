# Issue tracker: Local Markdown

Issues and specs for this repository live as Markdown files in `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`.
- The specification is `.scratch/<feature-slug>/spec.md`.
- Implementation issues are one file per ticket under `.scratch/<feature-slug>/issues/`, numbered from `01`.
- Each issue has a `Status:` line using the vocabulary in `triage-labels.md`.
- Comments and conversation history append under a `## Comments` heading.

When an engineering skill says to publish to the issue tracker, create the appropriate file under `.scratch/<feature-slug>/`.
