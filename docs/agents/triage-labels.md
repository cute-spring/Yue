# Triage labels

| Canonical role | Local tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required. |
| `needs-info` | `needs-info` | Reporter information is required. |
| `ready` | `ready` | Fully specified and ready for local Markdown implementation. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for agent implementation. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |
| `resolved` | `resolved` | Implemented and closed in the local Markdown tracker. |
