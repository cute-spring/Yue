Yue product roadmap

Built-In Skills as Workbench Modes

This roadmap turns six high-value skill patterns into Yue-native product capabilities. The goal is not to copy coding-agent commands into chat. The goal is to make Yue a trusted AI workbench where sources, tools, decisions, approvals, memory, and artifacts reinforce each other.

The six skills should become a small set of reusable work primitives: research with evidence, clarification with decisions, durable workspace language, session handoff, external discovery, and instruction quality review.

Product Position

Yue should expose these skills as productized workbench modes, not mainly as raw slash commands. Slash commands can remain as shortcuts, but the primary mental model should be visible user workflows: ask a grounded research question, clarify a vague task, save a session handoff, create a questionnaire, update workspace terms, or review an imported skill.

Evidence First

Claims should show whether they are source-supported, inferred, missing evidence, or user-confirmed.

Workspace Native

Outputs should attach to workspaces as artifacts, notes, glossary entries, or future runbook seeds.

Approval Gated

External or durable state changes need preview, provenance, and explicit user confirmation.

Low Friction

Yue should ask fewer, better questions and provide recommended answers when user decisions are needed.

Skill Roadmap Cards

1. Deep Research
P0User-facingEvidence
Workbench mode

Purpose: Turn source-backed questions into cited, durable research artifacts.

MVP

  • Research job form: question, sources, depth, output type.
  • Workspace source selection and citation requirement.
  • Research artifact with summary, findings, evidence, gaps, and next actions.

Prerequisites

  • Workspace sources and uploaded files are addressable by tools.
  • Grounding modes are productized.
  • Citation and missing-evidence states are visible.

Use: Trigger from `/research`, workspace source panel, attachment flow, or "research this" message action.

Value: Differentiates Yue from generic chat by making answers inspectable and reusable.

2. Clarify Mode
P0User-facingLow dependency
Conversation mode

Purpose: Convert vague requests into explicit decisions before Yue acts.

MVP

  • Ask one round of high-impact questions.
  • Include recommended answers.
  • End with a task brief or roadmap outline.

Prerequisites

  • Prompt-level skill injection works.
  • Auto-trigger rules avoid interrupting simple chats.
  • Manual shortcut is available.

Use: Trigger via `/clarify`, ambiguous high-cost requests, or before Research, Runbook, and Questionnaire flows.

Value: Prevents wrong-direction work while keeping user effort low.

3. Workspace Glossary
User-facingMemoryDesign first
Workspace capability

Purpose: Maintain shared project language and stable facts for each workspace.

MVP

  • Save confirmed terms into a workspace glossary.
  • Detect fuzzy or conflicting terms in chat.
  • Show provenance and confirmation status.

Prerequisites

  • Workspace-level memory or glossary storage.
  • User confirmation before durable writes.
  • Policy for term, fact, preference, and conclusion classes.

Use: Trigger through "remember this term", glossary panel, memory review queue, or term conflict detection.

Value: Makes Yue improve over time without silently persisting weak conclusions.

4. Session Handoff
P0User-facingArtifact
Artifact flow

Purpose: Preserve a useful chat as a continuation-ready workspace artifact.

MVP

  • Generate a structured handoff from the current chat.
  • Include decisions, sources, artifacts, open questions, and next actions.
  • Attach the handoff to the active workspace.

Prerequisites

  • Chat history and active skill state are readable.
  • Artifact or note save path is clear.
  • Sensitive values are redacted.

Use: Trigger from `/handoff`, message actions, workspace "summarize work", or before opening a new task.

Value: Turns transient chat into durable project memory and supports multi-agent continuation.

5. Discovery Questionnaire
User-facingLow dependency
Document artifact

Purpose: Convert missing human knowledge into a targeted questionnaire.

MVP

  • Ask who the questionnaire is for and what must be learned.
  • Generate a concise Markdown or HTML questionnaire.
  • Save it as an artifact with context and answer stubs.

Prerequisites

  • Artifact export or note creation.
  • Optional connector support for sending later.
  • Clear separation from Research when the blocker is a person.

Use: Trigger via `/questionnaire`, "ask someone else", or Research missing-info sections.

Value: Helps Yue handle real work where the missing source is a stakeholder, expert, or teammate.

6. Agent Instruction Review
AdminDeveloper-facing
Quality layer

Purpose: Review agent prompts and imported skills for trigger quality, safety, and runtime fit.

MVP

  • Analyze selected skill or agent prompt.
  • Report trigger, context load, allowed tools, safety, and examples quality.
  • Recommend fixes without turning Yue into an authoring IDE.

Prerequisites

  • Skill package and prompt metadata are readable.
  • Review rubric is stable.
  • Import gate compatibility report is available.

Use: Trigger from Skill Health, Skill Import preview, Agent editor, or internal built-in skill development.

Value: Improves routing accuracy and reduces prompt bloat across Yue's skill ecosystem.

Dependencies and Readiness

Ready Soon

Clarify Mode, Session Handoff, and Discovery Questionnaire can start with mostly prompt, chat history, and artifact plumbing.

Needs Trust Contract

Deep Research and Workspace Glossary need clear evidence, citation, provenance, and confirmation rules before they feel trustworthy.

Admin First

Agent Instruction Review should land inside Skill Health and Import Gate before becoming a general user-facing feature.

Decision Recommendation Reason
Primary interface Workbench modes with optional slash commands Matches Yue's chat-agent platform positioning and avoids exposing raw command mechanics as the main user model.
First three MVPs Clarify Mode, Session Handoff, Discovery Questionnaire They have low dependency risk and immediately improve day-to-day user workflows.
First trust-heavy MVP Deep Research over workspace sources It reuses Yue's document, PDF, citation, artifact, and trace foundations while creating a clear differentiator.
Memory write policy Explicit user confirmation before durable glossary or memory writes Prevents unsupported research conclusions and temporary chat state from becoming long-term workspace memory.
Instruction Review scope Review and recommend, not full authoring Preserves Yue's current boundary as a skill consumer, import gate, activation platform, and runtime.

Usage Model

Yue should let users reach these skills through natural language first, product controls second, and slash commands third. The same skill can be manually selected by advanced users or automatically suggested by runtime routing.

User says or does Yue response Resulting artifact
"Research this using my workspace files." Open Research Job with selected sources and citation requirement. Research report with evidence and gaps.
"Help me plan this feature." Ask a short decision round with recommended answers. Clarified task brief or roadmap outline.
"In this workspace, Source means an uploaded or indexed evidence file." Offer to save a confirmed glossary entry. Workspace glossary term with provenance.
"Summarize where we are so another agent can continue." Generate a redacted handoff from current chat state. Session handoff artifact.
"We need to ask the PM for missing requirements." Ask who receives it and what decisions are needed. Discovery questionnaire.
Admin imports or edits an agent skill. Analyze trigger fit, context load, tool policy, examples, and risks. Instruction quality report.

Out Of Scope For The First Roadmap

  • Do not build Yue into a full skill authoring IDE.
  • Do not auto-write long-term memory without user review.
  • Do not start with unrestricted web-wide autonomous research.
  • Do not require every user to understand slash commands.
  • Do not merge coding-agent workflows such as TDD, code review, and implementation into the global built-in set.
  • Do not let skill activation bypass Yue's import gate, compatibility checks, and tool policy.
Recommended next step: turn this roadmap into a formal implementation spec, then split it into small tickets: first Clarify Mode, Session Handoff, and Discovery Questionnaire; then Deep Research MVP; then Workspace Glossary and Agent Instruction Review.
